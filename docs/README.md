# OtoDepom - docs Klasörü (AI Context)
**Bağlam:** Proje dokümantasyonu, loglar ve değerlendirme belgelerinin klasörüdür.
**Görev:** AI ajan günlüğü (`ai-gunlugu.md`), proje final raporu (`rapor.md`) ve kanıt niteliğindeki ekran görüntüleri (`img/` alt klasöründe) burada tutulur.
**Kısıtlar:** Bu belgeler projenin tesliminde kullanılacağı için sürekli güncel tutulmalıdır. AI ajanı kod yazımından çok bu klasördeki günlük düzenine yardımcı olabilir ancak ekran görüntüleri manuel eklenir.
