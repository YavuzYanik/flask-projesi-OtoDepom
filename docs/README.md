# OtoDepom - Dokümantasyon Klasörü

Bu klasör (`docs/`), OtoDepom projesinin akademik değerlendirme sürecinde istenen zorunlu belgelerini ve proje metriklerini içerir.

## 📂 Klasör İçeriği

### 1. `rapor.md` (Proje Final Raporu)
Proje yönergesinde istenen 7 zorunlu sorunun (Projenin amacı, mimari yapı, Vibe Coding deneyimi, yapay zekanın yakaladığı hatalar vb.) cevaplarını içeren kapsamlı özeleştiri raporudur. Hocanın projeyi akademik olarak değerlendireceği ana kaynaktır.

### 2. `ai-gunlugu.md` (AI Oturum Günlüğü)
Yapay zeka ajanı ile "Vibe Coding" disiplinine uygun olarak geliştirilen bu projenin adım adım hikayesidir. Projenin tek bir dev prompt ile yapılmadığını, aşama aşama, ajana müdahale edilerek yapıldığını kanıtlar. İçerisinde kodlama süreçlerinde karşılaşılan hataların çözümleri ve ekran görüntüleri bulunmaktadır.

### 3. `Kanıtlar/` (Ekran Görüntüleri)
Yapay zekanın yaptığı planlara müdahale edildiği anları, terminalden alınan hata ekranlarını ve projenin "sorgulama-düzeltme" örneklerini içeren görsel kanıt (resim) klasörüdür.

---
*Not: Projenin genel kullanım kılavuzu (nasıl kurulur, nasıl çalıştırılır) bu klasörde değil, ana dizindeki `README.md` dosyasında yer almaktadır.*
